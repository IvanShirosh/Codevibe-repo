# Snippedle

A daily code-snippet guessing game — Wordle, but for programming languages.

Every day, everyone gets the same mystery snippet. Guess the language in 6 tries.

 How to play
1. Read the snippet in the mock editor window.
2. Type a language into the guess box (autocomplete will help).
3. 🟩 = correct · 🟨 = close (same language family) · ⬛ = not close
4. 6 guesses. New snippet tomorrow.

## Running locally
```bash
python3 -m http.server 8000
# open http://localhost:8000
```
